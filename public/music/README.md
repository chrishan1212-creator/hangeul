# 🎵 배경음악 바꾸기

이 폴더에 음악 파일을 넣으면 **자동으로 그 음악이 배경음악이 됩니다.**
파일이 없으면 앱이 직접 연주하는 잔잔한 기본 음악이 나옵니다.

## 어떻게 하나요?

1. 음악 파일(예: Suno로 만든 mp3)을 이 폴더에 넣습니다.

   ```
   public/music/우리집놀이터.mp3
   ```

   `.mp3`, `.m4a`, `.wav`, `.ogg` 모두 됩니다. 파일 이름은 아무거나 괜찮아요.

2. 커밋하고 push 하면 끝입니다. 코드를 고칠 필요는 없어요.

## 알아두면 좋은 점

- **여러 곡을 넣어도 됩니다.** 두 개 이상이면 순서를 섞어서 이어서 틀고,
  한 곡만 있으면 그 곡을 계속 반복합니다.
- **곡 길이는 1~2분이면 충분합니다.** 어차피 반복 재생되고, 파일이 크면
  로딩이 느려지고 데이터도 많이 씁니다. **3MB 이하**를 권합니다.
- 반복될 때 자연스럽도록 **끝과 시작이 이어지는 느낌**의 곡이 좋아요.
  (곡 끝에 긴 여운이나 갑작스러운 마무리가 있으면 반복될 때 어색합니다)
- 아이가 오래 듣는 음악이니 **가사 없는 잔잔한 곡**을 권합니다.
  말소리가 있으면 공룡 목소리와 겹쳐서 헷갈려요.
- 말하는 동안에는 배경음악이 자동으로 작아졌다가 돌아옵니다.
- 음량은 앱의 ⚙️ 설정에서 조절할 수 있어요. 곡 자체가 너무 크면
  넣기 전에 편집 프로그램에서 볼륨을 줄여두는 게 좋습니다.

## 저작권

직접 만들었거나 사용 권한이 있는 음악만 넣어주세요. AI로 만든 곡은
서비스마다 이용 약관이 다르니(무료 요금제는 보통 개인용으로 제한),
공개 배포할 계획이라면 해당 서비스의 약관을 확인하시는 게 좋습니다.

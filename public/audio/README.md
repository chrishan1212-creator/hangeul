# 🎙️ 목소리 파일 넣기

이 폴더에 음성 파일을 넣어두면, 앱이 기기 내장 목소리(TTS) 대신
**그 파일을 재생**합니다. 두 가지 방법이 있어요.

| 방법 | 품질 | 드는 노력 | 비용 |
| --- | --- | --- | --- |
| **A. 좋은 TTS로 자동 생성** | 아주 자연스러움 | 명령어 한 줄 | 무료 (아래 참고) |
| **B. 직접 녹음** | 엄마·아빠 목소리 💛 | 334개 녹음·편집 | 무료 |

둘을 **섞어도 됩니다.** 예를 들어 전부 TTS로 만들어두고, 아이가 가장 좋아하는
칭찬 문장 몇 개만 직접 녹음해서 덮어쓸 수 있어요.

## A. 좋은 TTS로 자동 생성 (권장)

앱이 말하는 문장은 **334개, 2,745자**로 정해져 있어서 한 번만 만들어두면 됩니다.
구글 TTS 무료 한도(월 10만 자)의 **2.7%** 라 사실상 무료예요.

```bash
npm run audio:tts -- --dry          # 무엇이 만들어질지 미리 보기
GOOGLE_TTS_API_KEY=키 npm run audio:tts   # 실제 생성
```

1. [Google Cloud Console](https://console.cloud.google.com) 에서
   **Text-to-Speech API** 를 켜고 API 키를 만듭니다
2. 위 명령을 실행하면 `public/audio/` 에 mp3 가 쌓입니다
3. 커밋하고 push 하면 끝

목소리·속도를 바꾸고 싶으면:

```bash
TTS_VOICE=ko-KR-Neural2-C TTS_RATE=0.9 GOOGLE_TTS_API_KEY=키 npm run audio:tts
```

이미 있는 파일은 건너뜁니다. 전부 다시 만들려면 `-- --force` 를 붙이세요.

## B. 직접 녹음

1. **어떤 파일이 필요한지 확인**

   ```bash
   npm run audio:list
   ```

   화면에 목록이 뜨고 `녹음목록.txt` 파일로도 저장됩니다.
   이미 녹음한 건 `[완료]` 로 표시돼요.

2. **녹음하기** — 아무 방법이나 괜찮아요.
   - 아이폰 **음성 메모** 앱 → 단어 하나씩 녹음 → 공유로 내보내기
   - 컴퓨터 녹음기, 또는 [Audacity](https://www.audacityteam.org/) 같은 무료 프로그램

   요령: 조용한 곳에서, 단어 앞뒤로 **무음을 최대한 짧게** 잘라주세요.
   앞에 1초씩 붙어있으면 게임 진행이 늘어집니다.

3. **파일 이름을 목록과 똑같이** 지어서 이 폴더에 넣기

   ```
   public/audio/사과.mp3
   public/audio/따라해보세요.mp3
   public/audio/는 어디 있을까요.mp3
   ```

   `.mp3` 외에 `.m4a`(아이폰 음성 메모 기본), `.wav`, `.ogg` 도 됩니다.
   아이폰 음성 메모에서 나온 `.m4a` 는 변환 없이 그대로 넣어도 돼요.

4. **커밋하고 push** — 배포되면 바로 그 목소리로 나옵니다.

## 알아두면 좋은 점

- **일부만 녹음해도 됩니다.** 없는 단어는 기기 목소리로 읽어줘요.
- **먼저 녹음하면 좋은 5개**: `따라해보세요`, `는 어디 있을까요`,
  `은 어디 있을까요`, `을 찾아보세요`, `를 찾아보세요`.
  이 5개만 있으면 모든 문제의 뒷부분이 사람 목소리가 됩니다.
- 질문은 **`단어` + `뒷부분`** 두 조각을 이어서 들려줍니다. 그래서 문장을
  통째로 녹음할 필요 없이, 단어 하나만 녹음하면 모든 문장에 재사용돼요.
- 한 문장 안에서 목소리가 섞이지 않도록, **두 조각이 모두 녹음되어 있을 때만**
  녹음을 씁니다. 한쪽이라도 없으면 그 문장은 통째로 TTS로 읽어요.
- 파일 목록은 빌드할 때 자동으로 다시 읽으므로 따로 코드를 고칠 필요가 없어요.
